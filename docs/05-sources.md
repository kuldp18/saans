# Research and source register

Initial verification on 24 November 2026. Use these stable source IDs in the UI, implementation catalog and tests. Before launch, confirm provider terms, model availability and region settings. The app is a decision aid for adult planners, and local advisories take precedence.

| ID | Source | Design implication |
| --- | --- | --- |
| WHO-AQG | [WHO Global Air Quality Guidelines](https://www.who.int/publications/b/59593), [pollutant guideline table](https://www.who.int/teams/environment-climate-change-and-health/air-quality-and-health/health-impacts/types-of-pollutants) | PM2.5 concentration and AQI are different. WHO's 15 µg/m³ PM2.5 guideline is for a 24-hour mean, so do not use it to label a single hour healthy or unsafe. |
| AIRNOW-AQI | [AirNow AQI Basics](https://www.airnow.gov/aqi/aqi-basics/) | Use named US categories for the modeled US AQI field. Pair every band with text. |
| AIRNOW-ACTIVITY | [AirNow Outdoor Activity Guidance for Schools](https://document.airnow.gov/air-quality-and-outdoor-guidance-for-schools.pdf) | Source principles around reducing intensity, duration and changing venue during pollution events. The app's stricter product gates are documented separately. |
| CPCB-INDIA | [CPCB National AQI dashboard](https://app.cpcbccr.com/AQIIndia), [India AQI interpretation](https://app.cpcbccr.com/ccr_docs/About_AQI.pdf) | Link to local official monitoring. India uses different bands and names, so do not convert a modeled US index into CPCB AQI. |
| EPA-HOME | [EPA Guide to Air Cleaners in the Home](https://www.epa.gov/indoor-air-quality-iaq/guide-air-cleaners-home), [EPA indoor source and exposure guidance](https://www.epa.gov/wildfire-smoke-course/strategies-reduce-exposure-indoors) | Prefer source control and suitable particle filtration. Use particle-smoke guidance for general particle reduction mechanisms only, with care around indoor sources, temperature and ventilation. Avoid numerical indoor reduction claims. |
| EPA-TRAVEL | [EPA passenger vehicle greenhouse gas explanation](https://www.epa.gov/greenvehicles/greenhouse-gas-emissions-typical-passenger-vehicle) | Gasoline combustion produces direct emissions. Use avoided private-car vehicle-km for this MVP. US fleet-average factors are unsuitable as an assumed India baseline. |
| OPEN-METEO-AIR | [Open-Meteo Air Quality API and attribution](https://open-meteo.com/en/docs/air-quality-api), [terms](https://open-meteo.com/en/terms) | Label Open-Meteo and CAMS. CAMS Global forecast resolution is about 45 km, so a city forecast cannot distinguish neighborhood-level conditions. The free endpoint is limited to noncommercial use and subject to usage caps. |
| GEMINI-MODEL | [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing), [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits), [deprecations](https://ai.google.dev/gemini-api/docs/deprecations) | Flash-Lite has a published free tier for eligible projects. Verify actual quota in AI Studio; the public demo has no dependency on this. |
| GEMINI-STRUCTURE | [Gemini structured output](https://ai.google.dev/gemini-api/docs/structured-output), [Gemini API terms](https://ai.google.dev/gemini-api/terms) | JSON schema constrains shape but application validation still matters. Unpaid services carry data-use and access restrictions, including age and region rules. No personal/sensitive data and no medical advice. |
| WCAG22 | [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/) | Target AA and verify with keyboard and assistive technology plus automated scans. Avoid claiming conformance from axe alone. |
| HOST | [Vercel Hobby](https://vercel.com/docs/plans/hobby), [Next.js production checklist](https://nextjs.org/docs/app/guides/production-checklist), [Upstash Redis pricing](https://upstash.com/pricing/redis) | Select a host compatible with the submission, document plan eligibility, and recheck any shared-store quota before enabling live services. |

Named product choices such as the twelve-hour search, conservative activity cutoff and cache TTL are engineering decisions. Catalog entries should cite the mechanism or source behind the advice. Exact example fixture numbers are synthetic.
